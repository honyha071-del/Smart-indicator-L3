# GOLD PULSE — Terminal Dashboard
A compact dark 3-by-2 dashboard matching the supplied reference layout.

## Publish
1. Create a GitHub repository.
2. Upload `index.html` to the root.
3. Settings → Pages → Deploy from a branch.
4. Select `main` and `/(root)`, then Save.

## Data status
The TradingView XAUUSD chart is an external embedded widget. Currency strength, COT, economic calendar rows and MTF bars are demo placeholders, clearly labelled in the page. They are not live readings or trading signals. Forex Factory has no generally available unrestricted public API for scraping. Live panels require a licensed data API and a secure backend/serverless function; do not expose API keys in public GitHub source.
